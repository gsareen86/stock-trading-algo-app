# Single-Stock Deep-Dive Checklist

When asked to research a specific NSE equity, cover these five independent facets clearly using tool results only:

1. **Company & Quality Profile (`company_quality`):**
   Report `ROE`, `Operating Margin`, `Sales YoY`, `EPS YoY`, `Debt/Equity` (or `not_applicable` for financial institutions), `Market Cap (INR Cr)`, and `P/E`. Label missing items `unavailable` rather than zero.

2. **Sector Context & Peer Comparison (`sector_rotation`, `peer_compare`):**
   Identify the company's NSE sector RRG quadrant and compare multi-month price relative strength against listed Indian peers.

3. **Management Commentary & Primary Catalysts (`commentary`, `transcript_summary`, `filings_scan`, `event_calendar`):**
   Summarize what management actually stated about demand, order book, capex, and risks, plus upcoming corporate actions or exchange filings.

4. **News & Internet Context (`news_research`, `web_search`):**
   Report recent sector/company news with explicit publisher and timestamps.

5. **Technical Setup Context (`setup_screener`):**
   If present in the latest scan, cite the named strategy's deterministic `Entry / Stop / Target` plan levels factually. Never invent a consolidated buy/sell call — verdicts remain strictly per-strategy.
